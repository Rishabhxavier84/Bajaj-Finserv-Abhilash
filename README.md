# Bajaj Finserv Hiring Challenge - Java + SQL

## 🚀 Project Overview
This project is a Spring Boot application built as part of the **Bajaj Finserv Hiring Assessment (JAVA)**.  
The application generates a webhook and processes responses as per the given instructions in the assignment PDF.

---

## 🧩 Tech Stack
- **Language:** Java 17+
- **Framework:** Spring Boot 3.5.7
- **Build Tool:** Maven
- **Database (for SQL Task):** MySQL (sample query provided)
- **IDE Used:** IntelliJ IDEA
